# Type Rush Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship Type Rush as a solo daily/practice fixed-passage typing game and
create the reusable typing primitives needed by Type Shield.

**Architecture:** Keep input normalization, progress, and metrics pure under
the shared domain package. Type Rush owns its prompt selection, round state,
storage, and React UI. Type Shield remains a later consumer with independent
wave and target rules.

**Tech Stack:** TypeScript ESM monorepo, Next.js 16, React 19, Vitest, local
storage adapters, Tailwind v4, and the existing game plugin registries.

## Global Constraints

- Domain rules remain framework-free and must not import React.
- Large dictionary JSON must not be statically imported into the Worker graph.
- Browser-only storage and random state must hydrate behind a stable loading
  branch.
- Use existing daily seed, engagement, storage, navigation, and UI patterns.
- Type Rush is solo-only in this slice; room synchronization is deferred.

## Delivered scope

- Paragraph is the default content type and uses a coherent deterministic
  three-to-five-sentence prompt.
- Practice settings also support Word Stream, Whole Numbers, and Decimal
  Numbers.
- Daily launch actions are content-specific and switch to `Play` for a fresh
  practice set after the daily is complete.
- Front-facing game actions and compact control options use Title Case,
  following `docs/QUALITY-CHECKLIST.md`.
