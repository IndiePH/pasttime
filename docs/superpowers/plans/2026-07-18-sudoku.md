## Global Constraints

- Domain package must never import React
- Storage daily key: `sudoku:daily:{difficulty}:{getDailySeed()}` — number seed stringifies (e.g. `sudoku:daily:easy:20260718`)
- Endless key: `sudoku:random:{difficulty}`
- Top-level `status`: `"playing" | "won" | "abandoned"` only (no `"lost"`)
- Mode query values: `"daily" | "random"` (Endless = `random`, matching other games)
- Difficulty query: `"easy" | "medium" | "hard"`
- No hints, share cards, variants, or multiplayer in this plan
- Peer conflicts only (not wrong-vs-solution red dots)
- Attempt cap for generation: `50`; fallback = best unique puzzle with rating ≤ target ceiling
- Follow TDD: failing test → implement → pass → commit per task
- Run domain tests with: `npm run test -w @pasttime/domain -- games/sudoku`

```ts
export type SudokuRoundMode = "daily" | "random"
export type SudokuStatus = "playing" | "won" | "abandoned"
export type SudokuTechnique =
  | "naked-single"
  | "hidden-single"
  | "naked-pair"
  | "hidden-pair"
  | "locked-candidate"
  | "naked-triple"
  | "hidden-triple"

/** 0 = empty for puzzle/solution grids of digits. */
export type SudokuGrid = number[] // length 81, values 0–9

export interface SudokuCell {
  /** Given clue — immutable when true. */
  given: boolean
  /** Player digit or 0 if empty. */
  value: number
  /** Candidate marks 1–9. */
  candidates: SudokuDigit[]
}

export interface SudokuPuzzle {
  /** Starting clues (0 empty). */
  givens: SudokuGrid
  /** Unique solution digits 1–9. */
  solution: SudokuGrid
  difficulty: SudokuDifficulty
  /** Seed used to generate (daily seed or random). */
  seed: number
  /** Hardest technique required (from rater). */
  ratingTechnique: SudokuTechnique
}

  puzzle: SudokuPuzzle
  cells: SudokuCell[] // length 81

  mode: SudokuRoundMode
  difficulty: SudokuDifficulty

  candidateMode: boolean
```

```ts
  return MODE_SET.has(v)

  return SUDOKU_ROUND_MODE_DEFAULT
```

```ts
// packages/domain/games/sudoku/rng.ts
import { hashSeed } from "../../daily"

export interface SudokuRng {
  next(): number // [0, 1)
  int(maxExclusive: number): number
  shuffle<T>(items: T[]): T[]
}

export function createSudokuRng(seed: number): SudokuRng {
  let state = hashSeed(seed) || 1
  const next = () => {
    state = (Math.imul(state, 1664525) + 1013904223) >>> 0
    return state / 0x100000000
  }
  return {
    next,
    int(maxExclusive) {
      return Math.floor(next() * maxExclusive)
    },
    shuffle(items) {
      const arr = items.slice()
      for (let i = arr.length - 1; i > 0; i--) {
        const j = Math.floor(next() * (i + 1))
        ;[arr[i], arr[j]] = [arr[j], arr[i]]
      }
      return arr
    },
  }
}
```

```ts
// board.ts — key exports
export const SUDOKU_SIZE = 9
export const SUDOKU_CELL_COUNT = 81

export function indexToRowCol(i: number): { row: number; col: number } {
  return { row: Math.floor(i / 9), col: i % 9 }
}
export function rowColToIndex(row: number, col: number): number {
  return row * 9 + col
}
export function boxIndex(row: number, col: number): number {
  return Math.floor(row / 3) * 3 + Math.floor(col / 3)
}
export function peerIndexes(index: number): number[] {
  const { row, col } = indexToRowCol(index)
  const peers = new Set<number>()
  for (let c = 0; c < 9; c++) peers.add(rowColToIndex(row, c))
  for (let r = 0; r < 9; r++) peers.add(rowColToIndex(r, col))
  const br = Math.floor(row / 3) * 3
  const bc = Math.floor(col / 3) * 3
  for (let r = br; r < br + 3; r++)
    for (let c = bc; c < bc + 3; c++) peers.add(rowColToIndex(r, c))
  peers.delete(index)
  return [...peers]
}

/** Legal candidates for an empty cell given current placed digits (peer constraints). */
export function legalCandidates(cells: { value: number }[], index: number): number[] {
  if (cells[index].value !== 0) return []
  const used = new Set<number>()
  for (const p of peerIndexes(index)) {
    const v = cells[p].value
    if (v >= 1 && v <= 9) used.add(v)
  }
  const out: number[] = []
  for (let d = 1; d <= 9; d++) if (!used.has(d)) out.push(d)
  return out
}
```

```ts
// conflicts.ts
import type { SudokuCell } from "./types"
import { indexToRowCol, boxIndex } from "./board"

export function findConflictIndexes(cells: SudokuCell[]): Set<number> {
  const conflicts = new Set<number>()
  const units: number[][] = []
  for (let r = 0; r < 9; r++) units.push(Array.from({ length: 9 }, (_, c) => r * 9 + c))
  for (let c = 0; c < 9; c++) units.push(Array.from({ length: 9 }, (_, r) => r * 9 + c))
  for (let b = 0; b < 9; b++) {
    const br = Math.floor(b / 3) * 3
    const bc = (b % 3) * 3
    const box: number[] = []
    for (let r = br; r < br + 3; r++)
      for (let c = bc; c < bc + 3; c++) box.push(r * 9 + c)
    units.push(box)
  }
  for (const unit of units) {
    const seen = new Map<number, number>()
    for (const i of unit) {
      const v = cells[i].value
      if (v < 1 || v > 9) continue
      if (seen.has(v)) {
        conflicts.add(i)
        conflicts.add(seen.get(v)!)
      } else {
        seen.set(v, i)
      }
    }
  }
  return conflicts
}
```

- [ ] **Step 3: Implement `rate.ts`**

Algorithm (must be pure, no guessing):

1. Copy givens into a working grid + candidate sets (legal candidates).
2. Loop applying techniques in order until stuck or filled:
   - naked single → place
   - hidden single (row/col/box) → place
   - naked pair → eliminate candidates
   - hidden pair → eliminate
   - locked candidates (pointing/claiming) → eliminate
   - naked triple / hidden triple → eliminate
3. Track the hardest technique that made progress.
4. If filled → map hardest → difficulty band.
5. If stuck → `{ solvable: false, difficulty: "unrated", hardest }`

Map hardest → difficulty:
- singles only → easy
- up to locked-candidate / pairs → medium
- up to triples → hard
- else unrated

- [ ] **Step 3: Implement generator**

Pipeline:

1. `fillGrid(rng)` — backtracking fill with shuffled digits → complete solution  
2. `countSolutions(grid, limit=2)` — backtracking count, abort at 2  
3. `carve(solution, rng)` — remove clues in shuffled order while `countSolutions === 1`; optional soft clue-count targets (easy ~36–40, medium ~30–34, hard ~24–28) but **do not** accept on clue count alone  
4. `rateSudoku(givens)` — accept if `difficulty` matches target; if rating is easier than target, keep carving or reject attempt; if harder/unrated, reject attempt  
5. Mix attempt seed: `hashSeed(seed + attempt * 9973)` via `createSudokuRng`  
6. After `maxAttempts`, pick best candidate with `rating ≤ ceiling` (never above). Prefer exact band; else nearest below.

Also export `createGameCellsFromPuzzle(puzzle): SudokuCell[]` helper (givens → cells with `given: true`).

```ts
import { generateSudoku } from "@pasttime/domain/games/sudoku"

self.onmessage = (event: MessageEvent<{ difficulty: "easy" | "medium" | "hard"; seed: number }>) => {
```

**Interfaces:**
- Consumes: storage, domain game/persistence/generate, worker helper, `useEngagementRecorder`
- Produces: `{ status: "loading" | "ready" | "error"; state; error; retry; selectCell; placeDigit; clearCell; toggleCandidateMode; setAutoCandidates; undo; elapsedMs }`

Behavior:
1. Compute `storageKey = getSudokuStorageKey(difficulty, mode)`
2. If parsed stored state → hydrate
3. Else generate: daily seed = `getDailySeed(new Date())`; random seed = `crypto.getRandomValues` → uint32
4. `createSudokuGame` then `storage.set` for **both** daily and random (unlike crossword ephemeral random — endless should resume)
5. Persist on every state change
6. `useEngagementRecorder({ gameId: "sudoku", variant: difficulty, status: state.status, isDaily: mode === "daily", time: floor(elapsed/1000) })`
7. Elapsed: `elapsedMs + (status === "playing" ? now - startedAt : 0)`; tick every 1s while playing
8. On worker failure set `status: "error"` with retry bumping a counter (do not write partial save)
